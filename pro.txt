Api Design and Development

- Rest api design and development

- EndPoints/ Resource Urls
  - api base url with versioning ex: https://api.source.in/v1/auth/login
  - proper json payloads
  - proper json response with consistency in keys stick to same rule

  - Ex: USER CRUD
    - GET /users list 200
      # use pagination, filter, search, export|import, Download, Multiple delete checkboxes
    - GET /users/:id single user 200(exits)|404(Not exists)

    - POST /users Create 201
    - Route Layer->validation middlewares

    ## 1. Route Layer Responsibilities
    - define endpoint
    - attach middlewares
    - call controller
    2. Validation layer middleware
    3. validation result middleware
    4. controller layer
       - recieve validated request
       - call service
       - send response
    5. service layer (duplicate check, hashing, data preparation, business rules, finally remove sensitive data)
    - server side validation
    - Duplicate check
    - prepare data to insert
    - run query
    - handle result
      - success
      - error
